# 🤖Telegram Bot

Минималистичный Telegram-бот на aiogram 3.x, реализующий функцию «эхо»:
отправляет обратно всё, что получает — текст, фото, стикеры, видео и документы.

Написан на Python, полностью асинхронный, использует long polling,
а также middleware для логирования всех входящих обновлений.

## 📦Функционал

💬 Эхо для текстовых сообщений
📸 Эхо для фотографий (в максимальном разрешении)
🎭 Эхо для стикеров
📹 Эхо для видео
📄 Эхо для документов (PDF, DOC, ZIP и др.)
📋 Логирование всего входящего трафика в консоль (в формате JSON)
⚡ Работает через Long Polling (встроенный в aiogram)
🐳 Поддержка запуска в Docker 

## 🚀Запуск
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/KseniyaBeskhmelnova/chat-bot-QA
2. Перейдите в папку проекта:
   ```bash
   cd <папка-проекта>
3. Создайте .env файл (пример есть в файле .env.example):
   ```bash
   pip install -r requirements.txt
4. Запустите бота одним скриптом:
   ```bash
   python -m bot
6. Остановка бота:
   Ctrl+c

## 🐳 Запуск в Docker
1. Сборка образа:
   ```bash
   docker build -t echo-bot .
2. Запуск с переменными из .env:
   ```bash
   docker run --rm --env-file .env echo-bot
